目的：区分 C3 输出异常更可能来自哪一个因素——带宽（8 kHz）、早期混响、完整混响、两人重叠、P2 约束。**只作诊断**，不是门控，也不写 c3_gate_v2。不跑分离前端，不修改 mix_v1、c3_gate_v1、P2 prompt、binding-score-v1 或已有结果。

## 指标（每个条件都报告）
- 目标至少命中一个、只含目标、两者都不含（binding-score-v1，只看解析出的实体值）。
  - 单人条件：对每条录音，按它在各组里的对手计算，再对录音取平均，与 `eval_c3_v1.py` 中 C1 的做法相同。
  - 混合条件：以样本为单位，s1 的目标是 A，s2 的目标是 B。
- **M = 与任一说话人 WER < 0.5 的条数**（normalize_v2 规范化后计算；单人条件里只有录音本人一个说话人）。
- **U = 和两句都无关的条数**：没有任何解析出的实体值等于参考值，并且对所有相关说话人的 WER 都 ≥ 0.5。
- 非英语条数（转写或原始输出中有非 ASCII 字母）；拒绝执行数（no_json，且命中 `postproc_c1_ext.REFUSAL`）；解析失败数。
- X1、X2、X3 逐项与 D2 比较。

## 解释规则（事先写定；用比例 m = M / 样本数，阈值 Δ = 0.15，绝对值）
| 因素 | 比较 | 认为"该因素有影响"的条件 |
|---|---|---|
| 带宽（单人） | C1 → C1b | m(C1) − m(C1b) ≥ 0.15 |
| 早期混响（单人） | C1b → C2 | m(C1b) − m(C2) ≥ 0.15 |
| 晚期混响（单人） | C2 → R1 | m(C2) − m(R1) ≥ 0.15 |
| 两人重叠（干声） | C1（这 40 个样本各自目标录音的 C1 结果）→ X1 | m(C1_40) − m(X1) ≥ 0.15 |
| 带宽（重叠语音） | X1 → X2 | m(X1) − m(X2) ≥ 0.15 |
| 混响 + 噪声（重叠语音） | X2 → D2 | m(X2) − m(D2) ≥ 0.15 |
| P2 约束 | D2 ↔ X3 | \|m(X3) − m(D2)\| ≥ 0.15，或 \|u(X3) − u(D2)\| ≥ 0.15（u = U / 40）；同时报告变化方向 |

- **主要来源**：在满足条件的因素中，m 下降最多的那个（P2 约束按 \|Δm\| 和 \|Δu\| 中较大的值参与比较）。如果没有任何因素满足条件，结论是"未能区分"。
- 差异小于阈值时，只能说"不能认定该因素有影响"，**不能**说"该因素没有影响"。
- 阈值是经验值，不是显著性检验。混合条件只有 40 个样本，0.15 约等于 6 条。
- 已知的混杂因素：C1 和 C1b 保持原始电平，而 C2、R1、X1、X2 统一缩放到 −30 dBFS，所以电平差异没有单独控制。
