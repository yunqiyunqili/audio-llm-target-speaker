# C5 重叠损伤诊断 v1（c5-overlap-damage-v1；2026-11-05；只读，在计算前写定；只作描述，**相关性不写成因果**，不新增音频）

## A. Whisper 错误拆分
- 对象：作业 22016221 的 W_C4direct（direct 参考）和 W_C5（C5 目标路），各 200 个样本。参考是目标句，两边都用 normalize_v2。
- 用 Levenshtein 对齐（替换、删除、插入的代价都是 1；回溯时一样好的情况依次优先替换、删除、插入），得到替换 S、删除 D、插入 I 的数量。检查 S + D + I 与 `slu_normalize.wer_counts` 的结果一致。
- 报告：两组各自的 S、D、I 总数和占参考词数的比例。
- 逐条比较：ΔWER = WER(W_C5) − WER(W_C4direct)，统计 C5 更差、相同、更好的条数，以及 ΔS、ΔD、ΔI 的总和。
- 列出 W_C5 中 WER 最高的 10 个样本：参考句、W_C5 转写、S/D/I，以及主要错误类型。主要错误类型规则：
  - 如果转写与干扰句的 WER 比与目标句的低，记为"偏向干扰者"；
  - 否则取 S、D、I 中最多的一项（并列时按替换、删除、插入的顺序取）；
  - 如果插入数超过参考词数，另外标注"大量插入"。

## B. 重叠帧诊断（C5 目标路，8 kHz）
- 帧：不重叠的 256 点帧（32 ms）。用目标和干扰者的 direct 参考分别判断有效帧，规则与 mix_v1 相同：帧功率 ≥ 该参考峰值帧功率 − 40 dB。
  - **只有目标说话**的帧：目标有效、干扰者无效；
  - **两人重叠**的帧：两者都有效；
  - 其余帧不参与统计。
- 分解：与 separation-quality-diag-v1 相同，零均值后做最小二乘，y = e_t + e_i + e_r，其中 e_t = a·d_T，e_i = b·d_I。
- 每一类帧，把帧内能量加总后计算：
  - 目标对干扰：10·log10(Σ‖e_t‖² / Σ‖e_i‖²)；
  - 目标对残差：10·log10(Σ‖e_t‖² / Σ‖e_r‖²)；
  - 目标对其余全部：10·log10(Σ‖e_t‖² / Σ‖y − e_t‖²)，相当于分段 SDR。
- 报告：两类帧上述指标的中位数和四分位数；两人重叠帧占全部有效帧的比例；按 C5 是否命中（"目标至少命中一个"）分两组比较。
- 实现：`scripts/sms_wsj/c5_overlap_damage.py`（A 和 B 都在里面；用 srun 在 CPU 节点运行），结果写到 `outputs/c5_overlap_damage_v1/`。
