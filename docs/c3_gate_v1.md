# C3 门控规则 v1（c3-gate-v1；2026-11-05 冻结，在 GPU 作业提交前写定，看到结果后不修改）

## 数据与条件
- 混合样本：`configs/mix_v1_devel100_v2.json`，100 组 × 2 个互换样本，音频在 `data/mix_v1/devel_seed2026/g*/mic0_16k.wav`（作业 22013065）。
- C3 的输入：mic 0 单通道混合信号（16 kHz）；文字为冻结的方向说明（`docs/mix_spec_v1.md`，θ1 四舍五入到整数度），后面接冻结的 P2 prompt。
- 每个互换样本的目标：s1 是 A（A 在 θ1），s2 是 B（B 在 θ1）；干扰者是同组的另一个人。
- 评分：slu-score-v2（`docs/scoring_rules.md`）和 binding-score-v1（`docs/binding_score_v1.md`），都不改动。
  - D_T = 目标 − 干扰，D_I = 干扰 − 目标，用 normalize_v2 处理后的实体值多重集合计算。
  - 只看解析出的 entities，按完整值匹配。解析失败时，实体按空集计。

## 定义
- 每个样本按 binding-score-v1 归为四类之一：只含目标、只含干扰、两者都含、两者都不含。
- **单人判定**：归为"只含目标"或"只含干扰"的样本。
- **目标占比** = 只含目标的样本数 / 单人判定的样本数。
- **95% 置信区间**：以**配对（组）为单位**做 bootstrap。从 100 组中有放回地抽 100 组，每组的两个互换样本一起进入；重复 10,000 次，`numpy.random.default_rng(2026)`；在每次重抽的样本上重新计算目标占比（某次重抽中单人判定为 0 时跳过，并记录次数）；取 2.5% 和 97.5% 分位数作为区间。选配对而不是说话人作为单位，是因为同一位说话人会出现在多组里，而每组的两个互换样本使用同一对录音，彼此不独立。

## 门控规则（按顺序判断）
1. 单人判定样本少于 50 个：**停止并报告**，样本不足，无法判断。
2. 置信区间下界 > 0.60：**停止**，怀疑存在泄漏。
3. 置信区间上界 < 0.40：**停止**，可能是模型偏向干扰者，或者数据有问题。
4. 其他情况：**通过**，可以进入前端推理。

阈值是经验值，看到结果后不修改。

## 同时报告（不参与门控）
- 四类比例；目标至少命中一个、目标全部命中（以样本为单位）。
- **配对翻转准确率** = 两个互换样本都归为"只含目标"的组数 / 100。也就是说，方位互换后，模型的答案也跟着换成了另一个人。
- **互换前后答案是否改变**：
  - (a) 按"答案指向谁"比较：每个样本的输出归为只含 A、只含 B、两者都含、两者都不含；两个互换样本的归类不同，就算"改变"。
  - (b) 两个互换样本解析出的实体值多重集合（normalize_v2 处理后）是否完全相同。
- 解析失败数、拒绝执行数（`scripts/qwen/postproc_c1_ext.py: REFUSAL`）、清单外的标签数。
- 分层探索（只作参考，不参与门控）：
  - 夹角：四层，[0,15)、[15,30)、[30,60)、[60,180]；
  - T60：[0.2,0.3)、[0.3,0.4)、[0.4,0.5]；
  - 有效帧重叠比例：[0,0.5)、[0.5,0.75)、[0.75,0.9)、[0.9,1]；
  - 完整 image 的 SIR：< −0.5、[−0.5,0.5]、> 0.5 dB。
  - 重叠比例和 SIR 是按样本记录的值，来自生成作业的 manifest。
- C1（同一个作业，干净录音，P2 prompt）：
  - 对涉及的 124 条录音，按它在每一组里的对手计算目标值是否命中；
  - 与作业 22011390 的 P2 结果比较重叠的 50 条录音：原始输出是否相同，解析出的实体是否相同。
