## Cross-Dataset Generalization 设计（仅方案，未启动）

目标是在不训练现有三条路线的前提下，检验 SLURP 之外的语音指令泛化。主验证集改为公开的 **Fluent Speech Commands (FSC)**：它提供独立的说话人、录音和 spoken-command 表达，适合检验跨数据集迁移。**MASSIVE 不再作为“完全独立”主验证集**；由于其任务体系和语义内容与 SLURP 存在继承/重叠可能，只能作为带严格文本、意图和 speaker 重叠审计的补充分析，不能单独支持独立跨领域泛化结论。

为避免标签体系不一致，评估前将每条样本映射到冻结的通用 JSON：`transcript`、`intent_family`、`slots`（统一为规范化 type/value），并只报告可映射的共同语义子集。主指标为 target-any、target-all、intent accuracy、slot precision/recall、parse failure、拒答覆盖率和作答风险；所有系统使用同一 prompt 输出格式与同一评分器，保留原始标签和映射表以便审计。

音频条件分为四层：单人干净原音；单人加真实或仿真的房间脉冲响应混响；双人空间化混合（两说话人、随机方位和 SIR 分层）；方向不确定性（目标 DOA ±10°/±20°、sector K8 以及 σ=10° 扰动）。双人条件沿用现有 SpatialNet 的 manifest、采样率和 route 定义，只替换语料音频；不重新训练 SpatialNet。

对比原始 Qwen 音频输入、Audio LoRA P2、Whisper+T2-LoRA T2 三条冻结路线。每个条件使用相同音频、相同样本顺序、相同重复次数和配对 bootstrap；先报告按数据集分层的结果，再报告跨数据集 pooled 结果。若 SLURP 上优势消失而独立数据集上下降，则标记为可能的 SLURP-specific overfitting，不据此调整 checkpoint 或阈值。

数据可获得性：FSC 作为主验证集，MASSIVE 仅作为补充；两者均需记录版本、下载日期、SHA256 和 speaker 列表。统一转码为 16 kHz、单声道 PCM；空间化使用已冻结的 RIR/SpatialNet 推理链，保存混合音频、DOA、SIR 和 route manifest。CPU 侧解析和统计无需 GPU；推理预算按三模型×数据集×四条件估算，优先分批复用现有推理脚本和权重，只有确认缺少输出后才申请 A100 作业。

主要泄漏风险包括：预训练语音模型可能见过公开语料、MASSIVE/Fluent 与 SLURP 的模板或实体重合、同一 speaker 出现在多个 split、以及 SpatialNet/RIR 生成参数被训练集暴露。方案要求按 speaker 去重、文本近重复检索、实体词表审计，并把所有跨数据集重合样本列入排除清单；最终 test 仍不在本阶段使用。
