# C6δ v1：询问方位带模拟误差时的端到端结果，以及简单拒答（c6-delta-v1；2026-11-05；规则在运行前写定，看到结果后不修改）

> **这里的方位误差是人为加上的固定偏移 δ（模拟误差），不是真实用户或真实定位器的误差。** δ = 0 就是 C5，依赖 oracle 方位。不下载、不微调模型，不加入新前端；不修改 mix_v1、P2/T2 prompt、binding-score-v1、已有结果或 v1/v2/v3 的判定。

## C6δ
- 前端：FaSNet-TAC 的现有输出。选路：冻结的 v3 规则（极性修正 → `doa` → 取最近的一路，一样近时取第 0 路）。询问方位 θ_query = wrap(θ1 + δ)，δ ∈ {0, +10, −10, +20, −20}。两路的估计方向直接用 `outputs/c5_v1/selection.jsonl` 里的值，与 direction-error-selection-v1 相同。
- 两路都需要 Qwen 输出：
  - C5 选中的那一路：直接用作业 22015337 的已有输出，不重跑；
  - **另一路**（1 − C5 选中的路）：本轮用 P2 补跑。处理与 C5 完全相同：按 v3 的极性标记修正 → `resample_poly(x, 2, 1)[:2T]` → −30 dBFS → 冻结的 P2，不加方向说明 → 解码设置与 P2 相同。
- 对每个 δ：每个样本取选中那一路的 Qwen 输出，再用 `eval_c4_v1.score` 和 `summ` 计算。报告只含目标、只含干扰、两者都不含、目标至少命中一个、目标全部命中、配对翻转准确率，以及 M 和 U。
- 分层：按夹角四层报告。另外**按 cv_dev93 的自然夹角分布加权**：[0,15) 78、[15,30) 96、[30,60) 155、[60,180] 653，共 982；加权值 = Σ（该层权重 × 该层指标）。配对翻转准确率不做加权，只报告未加权的值。
- 一致性：δ = 0 时的结果必须与 C5（eval_c5_v1）完全相同。

## 简单拒答
- margin = |wrap(θ_query − θ̂_另一路)| − |wrap(θ_query − θ̂_选中路)|，单位为度，按定义 ≥ 0。margin < τ 时输出"无法确定"，不使用这个样本的回答。
- 这条规则**只用估计方向和询问方位，不用参考信号，也不用说话人身份**。
- 按组分成两半：把 100 个组号排序后用 `random.Random(2026).shuffle` 打乱，前 50 组用来选阈值（dev），后 50 组用来评估（eval）。每组的两个互换样本放在同一半。
- 选 τ（只用 dev 一半，把五个 δ 的样本合在一起）：在 τ ∈ {0, 1, …, 90}° 中，取**最小的** τ，使得已回答样本中的选路错误率 ≤ 0.05。如果找不到，就取让错误率最小的 τ（一样小时取较小的 τ）。选路是否错误以 direct 参考匹配为标准，这只用来选阈值和评估，拒答规则本身不用参考。
- 在 eval 一半上，对每个 δ 报告：覆盖率（已回答的比例）、已回答样本中的选路错误率、已回答样本中"只含干扰"的比例、已回答样本中"目标至少命中一个"的比例；同时给出 τ = 0（不拒答）时的对照。
- 风险-覆盖率曲线：在 eval 一半上，对 τ ∈ {0, 1, …, 90}°，以覆盖率为横轴、已回答样本的选路错误率为纵轴，每个 δ 画一条线，图存为 `docs/figures/c6_risk_coverage_v1.png`。
- 不设判定阈值，只作描述。
