# C6δ（SpatialNet 快照）v1（c6-delta-spatialnet-v1；2026-11-05；规则在运行前写定，看到结果后不修改）

> - 只用 **SpatialNet-small 第 72 个 epoch 的快照**（`checkpoints/snapshots/spatialnet_ep72_20261105-211918/`，sha256 `582b2a3a…`）。这是**训练中的快照，只作诊断，不代表完成的模型**。
> - **δ 是人为加在真实方位上的固定偏移（模拟误差），不是估计方位，也不是真实用户的误差**。δ = 0 等于 C5 的设定，依赖 oracle 方位。本文**不定义真实的 C6**。
> - 不下载、不微调，不动训练作业，不使用 test，不修改已有的结果、prompt 或判定。

## 输入和已有输出
- 前端输出：`data/mix_v1/separated_v1_snapshot/spatialnet_ep72_20261105-211918/`（作业 22016833）。
- 两路的估计方向和极性标记：`outputs/frontend_snapshot_eval/spatialnet/selection.jsonl`（v3 规则，srun 22016898）。参考匹配的目标路来自同目录下 `per_sample.jsonl` 的 `ref_stream`，按 direct 参考 PIT 得到，**只用于评估**。
- 选中那一路的已有下游输出：作业 22016930 的 `P2/`、`W/`、`T2/`，**不重跑**。

## 补跑另一路
- 另一路 = 1 − 选中的路，按 v3 的极性标记处理（这个快照两路都被取反），走与 C5 相同的链路：resample_poly 2/1 → −30 dBFS。
- 分别跑冻结的 **P2**，以及 **Whisper large-v3（`06f233fe…`）+ 冻结的 T2**，设置与 22016930 完全相同。
- 实现：用 `scripts/sms_wsj/make_other_selection.py` 生成"另一路"的选路文件（stream 取 1 − stream，其余字段不变），然后**原样调用** `scripts/qwen/qwen_omni_snapshot.py`。
- 作业：`scripts/qwen/qwen_omni_snapshot_other.sbatch`，配置 <SLURM_ACCOUNT>、<GPU_PARTITION>、1 张 A100、4 CPU、48 GB、30 分钟。提交前工作区必须干净。记录 commit、节点、GPU 型号和每条耗时。

## 按 δ 组合与评估（与 c6-delta-v1 相同的规则）
- 询问方位 θ_query = wrap(θ1 + δ)，δ ∈ {0, +10, −10, +20, −20}。用 v3 的 `choose` 在已有的两路估计方向上选路，一样近时取第 0 路。选中哪一路，就取哪一路的下游输出。
- δ = 0 时的选路必须与 `selection.jsonl` 逐条一致，δ = 0 时的结果也必须与 22016930 的评估结果一致，否则停下。
- 指标（`eval_c4_v1.score` 和 `summ`）：选路错误率（以参考匹配为标准）、只含目标、只含干扰、两者都不含、目标至少命中一个、目标全部命中、配对翻转准确率、M、U。
- 两条下游路线（P2、Whisper + T2）分别报告。
- 夹角口径：等量夹角（即样本本身），以及按 cv_dev93 自然夹角分布加权（[0,15) 78、[15,30) 96、[30,60) 155、[60,180] 653）。配对翻转准确率不加权。
- 分层：夹角四层；T60 三层（[0.2,0.3)、[0.3,0.4)、[0.4,0.5]）。

## 拒答（与 c6-delta-v1 相同的流程）
- margin = |wrap(θ_query − θ̂_另一路)| − |wrap(θ_query − θ̂_选中路)|；margin < τ 时输出"无法确定"。只用估计方向，不用参考信号，不用说话人身份。
- 分组：组号排序后用 `random.Random(2026).shuffle` 打乱，前 50 组作 dev，后 50 组作 eval，与 FaSNet 的分组完全相同。
- τ：在 dev 一半上（五个 δ 合并），取 τ ∈ {0, 1, …, 90}° 中使已回答样本的选路错误率 ≤ 0.05 的最小值；找不到时，取错误率最小的 τ。
- 在 eval 一半上，对每个 δ、每条下游路线报告：覆盖率、已回答样本的选路错误率、只含干扰的比例、目标至少命中一个的比例，以及不拒答（τ = 0）时的对照。
- 风险-覆盖率曲线：画在 `docs/figures/c6_risk_coverage_spatialnet_v1.png`，与 FaSNet 的图格式相同。

### 描述（只是描述，不设判定，也不是显著性检验）
- 两个前端的选路错误率几乎一样（各个 δ 下都在 ±0.01 以内），因为选路只取决于估计方向，而两个前端的方向估计都很准。所以方向误差带来的选路问题与用哪个前端关系不大。
- 在各个 δ 下，SpatialNet 的端到端结果都比 FaSNet 高约 0.1–0.24（等量夹角）。但在 δ = +20 时，SpatialNet 的"只含干扰"达到 0.245（FaSNet 是 0.14）：分离得越干净，选错路时就越完整地输出了干扰者的内容。
- 在 SpatialNet 上，P2 比 Whisper + T2 高 0.005–0.045。
- 拒答（τ = 17°）在 eval 一半上，除 δ = +20 外，都把选路错误率和"只含干扰"降到了 0，已回答样本的"目标至少命中一个"在 0.64–0.72 之间；代价是覆盖率只有 0.50–0.72。
