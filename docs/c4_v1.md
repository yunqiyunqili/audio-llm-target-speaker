# C4 v1：参考匹配选路 → Qwen P2（c4-v1；2026-11-05；规则在运行前写定，看到结果后不修改）

**C4 只作离线诊断，不代表系统性能**，因为选路用到了参考信号。不跑 C5，不写方向匹配 v2，不加入新前端；不修改 mix_v1、P2 prompt、binding-score-v1、已有结果或 v1/v2 的判定。

## 条件
- 前端：BLSTM+MVDR、FaSNet-TAC，使用 `data/mix_v1/separated_v1/<frontend>/` 中已有的输出（作业 22014183），不生成新的前端输出。
- 选路：按 **direct 参考匹配**选出目标路，结果在 `outputs/frontend_mix_v1_eval_v2/eval_v2_per_sample.jsonl` 的 `ref_stream_direct` 字段；作业记录这个文件的 sha256。
- 预处理：
  1. 8 kHz 输出用 `resample_poly(x, 2, 1)` 升到 16 kHz，截到 2T。这与 C1b 中升采样那一步相同。
  2. 统一电平：把 16 kHz 信号缩放到有效帧 RMS = −30 dBFS。有效帧定义：不重叠的 32 ms 帧（16 kHz 下 512 点），帧功率 ≥ 峰值帧功率 − 40 dB。
  3. 不做其他增强。
- Prompt：冻结的 P2（`qwen_omni_c1_p2t2.PROMPT_P2`），**不加方向说明**。解码设置与 P2 相同：贪心解码，max_new_tokens 256，batch 1，只输出文本。
- 样本：200 个（100 组 × 2 个互换样本）。s1 的目标是 A，s2 的目标是 B。
- 作业配置：<SLURM_ACCOUNT>、<GPU_PARTITION>、1 张 A100、4 CPU、48 GB、30 分钟。提交作业前工作区必须干净。

## 对照
- **C3**：作业 22014089 的 C3，同样 200 个样本，是混合信号加方向说明。
- **R1**：作业 22014155 的 R1，是目标录音单人加完整混响，P2，−30 dBFS。对每个样本，取目标录音的 R1 输出，按**这个样本自己的配对**（D_T = 目标 − 干扰，D_I = 干扰 − 目标）判定类别，所以 R1 同样有 200 个样本口径的数值。

## 指标（slu-score-v2 和 binding-score-v1，都不改动）
- 四类比例（只含目标、只含干扰、两者都含、两者都不含）、目标至少命中一个、目标全部命中。只看解析出的实体值。
- 配对翻转准确率：两个互换样本都归为"只含目标"的组数 / 100。
- M：与任一说话人 WER < 0.5 的条数。C4 和 C3 看目标和干扰两人；R1 只看目标本人。
- U：和两句都无关的条数，定义与 c3-factor-diag-v1 相同。
- 解析失败数、拒绝执行数（no_json，且命中 `REFUSAL`）。
- 分层（只作探索）：夹角、T60、有效重叠比例、完整 image SIR，分层边界与 frontend_mix_v1 相同。

## 判定（每个前端分别判断；经验值，不是显著性检验）
- 记 a(X) 为条件 X 在 200 个样本上的"目标至少命中一个"比例。
- **a(C4) − a(C3) ≥ 0.15**：判为"分离有帮助"；否则判为"不能认定分离有帮助"。
- 记 gap = a(R1) − a(C4)：
  - gap ≤ 0.10：判为"失真不是主要障碍"；
  - gap > 0.10：判为"失真仍是主要障碍"。

## FaSNet-TAC 方向不对称诊断（只读；不生成新的前端输出，不修复，不改选路规则）
方向估计器与 v1/v2 相同（`eval_frontend_mix_v1.doa`）。
1. 把 direct 参考代入估计器：目标的 direct 参考与 θ1 比较，干扰的 direct 参考与 θ2 比较，报告误差。
2. FaSNet-TAC 的两路分别与两个 direct 参考比较（输出路按 direct 参考匹配归属）：
   - 时间偏移：互相关峰值所在的滞后，范围 ±400 个采样点；
   - 峰值处的归一化相关；
   - SI-SDR。
3. 方向误差（|wrap(θ̂ − 该路所属说话人所在的方位)|）分别按以下方式分组报告：输出路编号 0/1、s1/s2、说话人 A/B、所在位置 θ1/θ2。
4. 列出目标路误差最大和最小的各 10 个样本。
5. **判断规则**（按顺序判断，取第一个满足的）：
   - **评估定义**：direct 参考在 θ1 和 θ2 上的误差中位数，一个 > 10°、另一个 ≤ 10°。
   - **输出路编号**：按输出路编号分组的误差中位数，一个 > 30°、另一个 ≤ 10°，并且按 θ1/θ2 分组时不出现同样的分化。
   - **时间或相位问题**：按 θ1/θ2 分组的误差有分化（一个 > 30°、一个 ≤ 10°），并且误差大的那一组，与自己 direct 参考的时间偏移中位数 |lag| ≥ 2 个采样点，或峰值相关的中位数比另一组低 ≥ 0.2。
   - 都不满足：**暂时无法确定**。

## FaSNet-TAC 方向不对称诊断结果
- **direct 参考代入估计器**：θ1 的误差中位数 0.37°，θ2 是 0.38°，两者全部 ≤ 10°。所以不是评估定义的问题。
- **按输出路编号分组**：

| | 方向误差中位数 | 误差 ≤ 10° 的比例 | 与自己 direct 参考的相关（中位数） | 时间偏移中位数 | 与自己 direct 参考的 SI-SDR 中位数 |
|---|---|---|---|---|---|
| 第 0 路 | 120.9° | 0.00 | **−0.89** | 0 | 5.97 dB |
| 第 1 路 | 0.76° | 1.00 | +0.90 | 0 | 6.36 dB |

- 按其他方式分组：
  - θ1 / θ2：误差中位数 77.9° / 2.0°，相关中位数 −0.81 / +0.81。第 0 路有 115/200 次被选为目标路，所以 θ1 上的误差大。
  - s1 / s2：35.6° / 32.0°，没有差别。
  - A / B：61.5° / 5.4°。
  - 输出路 × 位置：第 0 路在 θ1、θ2 上的误差中位数是 117° / 129°，第 1 路是 0.76° / 0.76°。所以误差只跟输出路编号有关，跟位置无关。
- **目标路误差最大的 10 个样本**全部是第 0 路，误差 172–180°，相关在 −0.80 到 −0.92 之间，只有 g074_s1 是 −0.20：g032_s2、g005_s2、g074_s1、g092_s1、g063_s2、g063_s1、g083_s2、g083_s1、g049_s2、g026_s1。
- **误差最小的 10 个样本**全部是第 1 路，误差 ≤ 0.17°，相关在 +0.76 到 +0.97 之间：g034_s1、g084_s1、g030_s1、g057_s1、g096_s1、g096_s2、g080_s1、g009_s2、g010_s1、g010_s2。
- **按冻结规则判断：时间或相位问题。**
  - θ1 和 θ2 的误差有分化，误差大的一组（θ1），与自己 direct 参考的相关比另一组低 1.62，超过 0.2 的阈值。
  - 规则中的"输出路编号"一条没有成立，因为它要求按 θ1/θ2 分组时不出现同样的分化，而这里出现了。
- **事实说明**（只是描述，不修复）：FaSNet-TAC 第 0 路的输出与它对应的直达声**极性相反**，相关约 −0.89，时间偏移为 0。
  - SI-SDR 不受符号影响，所以分离指标不受影响。
  - 但方向估计器用的是 PHAT 互谱的相位，符号翻转让估计方向偏到接近相反的方向（172–180°）。
  - 所以，这里说的"相位问题"具体就是第 0 路的极性翻转，它只和输出路编号有关。
- 选路规则没有修改，也没有修复。v1/v2 的判定不变。
