# 关键实体值绑定评分 v1（binding-score-v1，2026-11-05）

主指标的定义见 `docs/conditions.md`。实现：`scripts/slurp/binding_score_v1.py`。规范化使用 `docs/scoring_rules.md` 中的 normalize_v2。

## 定义
- 配对 (T, I)：v2 devel 候选对（同一 split、意图相同、实体类型多重集合相同、实体值不同、说话人不同），并且同性别、时长差 ≤ 1 s。
- D_T = T − I，D_I = I − T：用 normalize_v2 处理后的实体值多重集合相减。类型不参与比较，因为两句的类型多重集合相同。只有 D_T 和 D_I **都非空**才算有效配对。
- 主指标：**只看解析出的 entities 的值**，按完整值匹配（多重集合）。
  - 目标命中 = D_T 中的值全部出现（计入重复次数）；干扰命中 = D_I 中任一个值出现。
  - 四类：只含目标（目标命中且没有干扰命中）、只含干扰、两者都含、两者都不含。
  - 另外报告：目标至少命中一个；目标命中率 = |D_T ∩ H| / |D_T|。
- 诊断（不作主指标；只报告 P0、P1）：把"值作为完整词串出现在规范化后的转写里"算作命中，其余规则相同。
- 解析失败时，输出实体按空集计。
- 汇总：先对每条目标录音，在它的所有有效干扰者上计算各类比例和命中率，再对录音取不加权平均。"范围"指每条录音在不同干扰者之间命中率的最小值和最大值。

## 适用范围
目前只有 C1 干净语音的结果（作业 22010997），只检查目标说话人自己的干净输出里包含哪些值。**这不是混合语音的结果**，也不计算配对翻转。

## 结果（22010997；目标为 configs/c1_ext_devel100.json 中的 76 条 tier 1 录音）
- 76 条录音都至少有 1 个有效干扰者；共 190 个（目标, 干扰者）组合，每条录音有 1–8 个干扰者。
- 输出：`outputs/qwen_omni_c1_ext_post/22010997/binding_v1/`。

|---|---|---|---|---|---|---|---|
| P0 实体 | 0.272 | 0.003 | 0 | 0.725 | 0.404 | 0.338（0.329 / 0.349） | 2 |
| P1 实体 | 0.237 | 0 | 0 | 0.763 | 0.368 | 0.303（0.303 / 0.303） | 0 |

- 每条录音单独的命中率都在 0 到 1 之间。
- 出现"干扰命中"的几种情况，都是完整值匹配本身带来的假象，不是真的绑定到了干扰者：
  - P0 和 T0：参考值是 "tomorrows"，模型输出 "tomorrow"，恰好等于某个干扰者的值。
  - 转写诊断：干扰者的值 "john" 作为一个词出现在 "tara john" 里。
