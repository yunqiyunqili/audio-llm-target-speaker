# 实验条件表

来源：研究方案（2026-11-03 由项目负责人确认）。第一轮所有空间条件都在 8 kHz 下构造，不重新生成 RIR。

| 条件 | 输入 | 下游 |
|---|---|---|
| C0 | 目标说话人转写（文本） | 文本 LLM |
| C1 | 目标干净语音，SLURP 原始带宽 | Audio LLM |
| C1b | C1 降采样到 8 kHz，再升采样到 16 kHz | Audio LLM |
| C2 | 目标早期混响语音：8 kHz 下与 SMS-WSJ early RIR 卷积，再升到 16 kHz | Audio LLM |
| C3 | 单通道混合 + 方向提问 | Audio LLM |
| C4 | 分离流 + 参考语音匹配选流（**仅离线诊断**） | Audio LLM |
| C5 | 分离流 + 真实方位选流 | Audio LLM |
| C6 | 分离流 + 用户给出的目标方向（扇区或带误差的角度）+ 系统估计的声源方向选流（`docs/c6_real_v1.md`） | Audio LLM |
| C7 | C5、C6 选出的语音 → ASR → 文本 | 文本 LLM |

## 约定
- **混响损失** = 指标(C1b) − 指标(C2)。两者都经过 8 kHz 瓶颈，所以差值只反映早期混响，不混入带宽损失。带宽损失可以另用 C1 − C1b 计算。
- **方位**统一使用相对 mic 0 的角度：az_rel = wrap(az(源 − 阵列中心) − az(mic0 − 阵列中心))，取值 (−180°, 180°]。两说话人夹角 = |wrap(az1 − az0)| ∈ [0°, 180°]。实现见 `scripts/sms_wsj/sms_wsj_geometry_stats.py`。
- 升采样到 16 kHz 是为了匹配 Qwen2.5-Omni 的 WhisperFeatureExtractor（sampling_rate 16000，见 `docs/log/day1_followup.md` §6）。升采样滤波器尚未确定，需要固定并写入配置。

## C2 的 early 定义：沿用现有 SMS-WSJ 数据
已核对官方代码 `repos/sms_wsj`（commit `f6b94bb9`）的 `sms_wsj/database/utils.py: scenario_map_fn`；本地已生成的 `early/` 数据由 `write_files.py` 使用默认参数生成，没有覆盖该参数。具体定义：
1. `rir_start` = `get_rir_start_sample(h_k)`：对每个说话人的 6 通道 RIR，在每个通道上找第一个满足 |h| > 0.1·max|h| 的样本，再取 6 个通道中的最小值。这就是直达声到达时刻。
2. `early_rir_samples` = int(8000 × 0.05) = **400 个样本（50 ms）**，从 `rir_start` 开始算。early RIR = h[0 : rir_start + 400]，其余位置置零，所以包含传播时延，加上直达声之后的 50 ms。tail 是其余部分。
3. 与源信号卷积后，按 `offset − rir_start` 对齐，再乘以与完整 image 相同的 gain（由 log_weights 和 6 通道 image 的 std 决定，再 /71）。
4. C2 沿用这一定义：SLURP 目标语音降到 8 kHz → 与该房间 mic 0（第 0 通道）的 early RIR 卷积 → 按第 3 点对齐 → 升到 16 kHz。
5. 与 SMS-WSJ 原数据的区别：SLURP 语音不是 WSJ，gain 和 offset 要按新混合重新确定，具体规则待写入数据生成脚本。

## 指标（2026-11-05 决定）
### 主指标：关键实体值绑定（配对实验）
- 对象：一个配对 =（目标说话人语句 T，干扰者语句 I）。按配对规则，两句意图相同、实体类型多重集合相同、实体值不同。
- **区分实体值**：在 T 的实体值里、但不在 I 的实体值里的值，是目标的区分值；反过来是干扰者的区分值。比较时用 normalize_v2（`docs/scoring_rules.md`）。
- 对每个配对、每个条件的输出，判断两件事：
  1. 输出中是否包含目标的区分实体值；
  2. 输出中是否包含干扰者的区分实体值。
- 由此可以分成四类：只含目标（绑定正确）、只含干扰者（绑定到干扰者）、两者都含、两者都不含。
- **实现：未实现。** 还没确定的细节：在解析出的实体值里查找，还是在整个输出文本里查找；多个区分值时按全部还是按任一计算；具体实现时写入 `docs/scoring_rules.md` 并升级版本号。
### 辅助指标
严格 SLU 实体 F1、意图准确率、转写 WER（定义见 `docs/scoring_rules.md`）。已有的结果不修改。

## C6δ 与 C6 的区别（2026-11-05）
- **C6δ**（`docs/c6_delta_v1.md`）：在 C5 的**真实询问方位**上加一个人为的固定偏移 δ（0、±10°、±20°），只用来模拟询问方向的误差。**它不是估计方位**，也不代表真实用户或定位器的误差分布。
- ~~真实的 C6 尚未定义~~（2026-11-05 的写法，已由下条取代）。
- **真实的 C6**（2026-11-06 冻结，`docs/c6_real_v1.md`）：**不从混合音频估计目标方向**（混合音频本身不能说明用户要听谁）。目标方向由用户提供，系统用 v3 的 `doa` 估计各分离流的声源方向，取离用户方向最近的一路。用户输入分两种模拟：
  - **C6-sector**：用户只给出目标所在扇区（相对 mic 0，mic 0 方向为扇区中心），询问方向取扇区中心；主结果为 8 扇区。两人在同一扇区时为"方向不可辨"，选路不算正确。
  - **C6-noise**：询问方向 = θ1 + 高斯误差（σ = 5°、10°、15°，按组抽样，重复 10 次）；主结果为 σ = 10°。
- C6δ 继续保留，只作敏感性分析。
