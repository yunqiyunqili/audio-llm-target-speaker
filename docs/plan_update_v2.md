# 方案更新 v2（2026-11-06）

> **适用范围（所有数字都受此限制）**
> - 所有结果**只来自 mix_v1 的 100 组 devel**（200 个互换样本；单人条件为 124 条录音或其映射），每个条件只跑了一次。**没有使用任何 test 数据。**
> - 涉及 SpatialNet-small 和 TF-GridNet 的结果都来自**训练中的快照**（SpatialNet 第 72 个 epoch、TF-GridNet 第 16 个 epoch），**只是快照诊断**，不代表完成的模型。
> - 所有判定阈值都是经验值，没有做显著性检验（c6-real-v1 给出了组级 bootstrap 区间，但判断仍按点估计）。
> - **音频 LLM 相对"ASR + 文本 LLM"的优势尚未证明。**

## 2. 未确认的假设
1. **音频 LLM 的优势尚未证明**：同一前端输出上，P2 比 Whisper + T2 高 0.030–0.055（SpatialNet 快照 C5 0.635 vs 0.590；C4-direct 0.670 vs 0.640；FaSNet C5 0.395 vs 0.340），都没有显著性检验，也只在 devel 上。
2. FaSNet-TAC 的残差来源（重叠残留、非线性失真或其他）没有因果证据。
3. 完成训练的 SpatialNet / TF-GridNet 是否保持快照上的水平，未知。
4. 方向不确定性的严重程度对扇区粒度很敏感：8 扇区的"只含干扰"是 0.049（离 0.05 只差 0.0011），4 扇区是 0.075。真实用户会怎样给出方向，没有测量。
5. BLSTM+MVDR 在 mix_v1 与 cv_dev93 上差距大的原因未查明；"领域差异"是排除法得出的判断。
6. devel 结果可能偏乐观：极性修正、τ = 17° 等都是在 devel 上看过结果之后定的；devel 只有 11 个说话人。

## 3. 新的主线（2026-11-06 项目负责人决定）
1. **前端**：以 SpatialNet-small 为主前端。训练完成后，用完成的 checkpoint 按现有规则（cv_dev93 核查 → mix_v1 选路 → 两路的 P2 和 Whisper + T2 → C5、C6δ、c6-real-v1）重跑；**完成时先报告，等批准后再提交作业**。
2. **方向不确定性**：保留为"小夹角或粗粒度输入下的问题"，不作为当前主攻方向。
   - margin 拒答（τ = 17°）和扇区拒答 B 作为后续所有条件的**基线**；
   - 主条件为 8 扇区、σ = 10°；**4 扇区只作敏感性分析**；
   - C6δ 继续只作敏感性分析。
3. **下游**：主要瓶颈转到下游的目标实体抽取。新增 LoRA 方案草案（`docs/lora_slu_plan_draft.md`，只写方案，未批准、未运行），比较 P2、LoRA 微调后的 Qwen、Whisper + T2。
4. **对照**：Whisper + T2 一直作为"ASR + 文本 LLM"对照，用来检验音频 LLM 是否有优势。

## 4. 对原方案的修改
| 原方案 | 修改 | 原因 |
|---|---|---|
| C6 = 分离流 + 估计方位选流 | C6 = 用户给出目标方向（扇区或带误差的角度）+ 系统估计声源方向选流（`c6_real_v1.md`，`conditions.md` 已更新） | 混合音频本身不能说明用户要听谁 |
| M3 | **暂停**（定义见本节下方） | 真实 C6 判为只在小夹角或部分条件下重要 |
| C7 = 分离语音 → ASR → 文本 LLM | ASR 固定为 Whisper large-v3（revision `06f233fe…`），文本 LLM 用冻结的 T2；Qwen 自身转写的方案 A 不再作为主对照 | 方案 A 的转写经常变成回应指令（WER 3.96） |
| FaSNet-TAC 为主前端 | FaSNet-TAC 改为对照；**另一路的 Whisper + T2 不补跑** | 快照前端明显更强；FaSNet 只对照 P2 |
| 不微调 | 增加 LoRA 方案草案，**仍需批准**才能运行 | 下游实体抽取成为主要差距 |
| 不拒答 | margin 拒答和扇区拒答 B 作为基线 | 两者在主条件上都能把"只含干扰"降到一半以下，覆盖率 ≥ 0.60 |

**M3 的定义**（补充上表"M3 暂停"一行；来源：2026-11-03 原方案 PDF"提出的方法与消融实验"一节）：

M3（LLM 级融合，主方法候选）：把两路分离语音、每路与目标方向的匹配度，以及可靠性信息一起交给 LLM。可训练部分为可靠性估计器 + LoRA。可靠性特征（首轮）：目标方向与每路估计方向的差值、方向谱峰值清晰度、两路输出的相似度和残留串扰、分离流的能量和可懂度代理指标。输入方式按成本从低到高：prompt 中提供两路语音、方向和离散可靠性等级 → 可学习的可靠性 token → 逐帧加权。训练目标：结构化输出（意图、实体、置信等级或"无法确定"），使用翻转样本，方向不可辨时以"无法确定"监督。对照：M1 硬选流（无训练）、M2 可靠性选流（小型可靠性估计器）。

暂停原因不变：c6-real-v1 判为"只在小夹角或部分条件下重要"，且 SpatialNet 在可辨样本上的选路错误率为 0。
