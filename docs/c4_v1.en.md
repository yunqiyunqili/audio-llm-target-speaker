# C4 v1: reference-matched stream selection → Qwen P2 (c4-v1; 2026-11-05; rules written before the run and not changed after the results were seen)

**C4 is an offline diagnosis only and does not represent system performance**, because stream selection uses reference signals. C5 is not run, no direction matching v2 is written, and no new front end is added; mix_v1, the P2 prompt, binding-score-v1, existing results and the v1/v2 verdicts are not changed.

## Conditions
- Front ends: BLSTM+MVDR, FaSNet-TAC, using the existing outputs in `data/mix_v1/separated_v1/<frontend>/` (job 22014183); no new front-end outputs generated.
- Stream selection: the target stream selected by **direct-reference matching**, recorded in the `ref_stream_direct` field of `outputs/frontend_mix_v1_eval_v2/eval_v2_per_sample.jsonl`; the job records the sha256 of this file.
- Preprocessing:
  1. The 8 kHz output is upsampled to 16 kHz with `resample_poly(x, 2, 1)` and truncated to 2T. This is the same as the upsampling step in C1b.
  2. Level normalisation: scale the 16 kHz signal to active-frame RMS = −30 dBFS. Active-frame definition: non-overlapping 32 ms frames (512 points at 16 kHz), frame power ≥ peak frame power − 40 dB.
  3. No other enhancement.
- Prompt: the frozen P2 (`qwen_omni_c1_p2t2.PROMPT_P2`), **without the direction instruction**. Decoding as for P2: greedy decoding, max_new_tokens 256, batch 1, text output only.
- Samples: 200 (100 groups × 2 swapped samples). The target of s1 is A, of s2 is B.
- Job configuration: <SLURM_ACCOUNT>, <GPU_PARTITION>, 1 A100, 4 CPU, 48 GB, 30 minutes. The working tree must be clean before job submission.

## Controls
- **C3**: C3 of job 22014089, the same 200 samples, mixture signal plus direction instruction.
- **R1**: R1 of job 22014155, target recording single-talker plus full reverberation, P2, −30 dBFS. For each sample, take the R1 output of the target recording and judge its class with **that sample's own pair** (D_T = target − interferer, D_I = interferer − target), so R1 also has values on the 200-sample basis.

## Metrics (slu-score-v2 and binding-score-v1, both unchanged)
- The four class proportions (target only, interferer only, both, neither), target-any, all target values hit. Parsed entity values only.
- Pair-flip accuracy: number of groups in which both swapped samples are classed "target only" / 100.
- M: number of items with WER < 0.5 against either talker. C4 and C3 consider both target and interferer; R1 considers only the target.
- U: number of items unrelated to both sentences, defined as in c3-factor-diag-v1.
- Number of parse failures, number of refusals (no_json and matching `REFUSAL`).
- Strata (exploration only): angle, T60, active overlap ratio, full-image SIR, with the same stratum boundaries as frontend_mix_v1.

## Verdict (judged separately per front end; empirical, not significance tests)
- Let a(X) be the target-any proportion of condition X over the 200 samples.
- **a(C4) − a(C3) ≥ 0.15**: verdict "separation helps"; otherwise "it cannot be established that separation helps".
- Let gap = a(R1) − a(C4):
  - gap ≤ 0.10: verdict "distortion is not the main obstacle";
  - gap > 0.10: verdict "distortion is still the main obstacle".

## FaSNet-TAC direction-asymmetry diagnosis (read-only; no new front-end outputs, no fix, no change to the stream-selection rule)
The direction estimator is the same as v1/v2 (`eval_frontend_mix_v1.doa`).
1. Substitute the direct references into the estimator: compare the target's direct reference with θ1 and the interferer's direct reference with θ2, and report the errors.
2. Compare each of the two FaSNet-TAC streams with the two direct references (streams assigned by direct-reference matching):
   - time offset: the lag of the cross-correlation peak, within ±400 samples;
   - normalised correlation at the peak;
   - SI-SDR.
3. Direction errors (|wrap(θ̂ − the azimuth of the talker the stream belongs to)|) reported grouped separately by: output-stream index 0/1, s1/s2, talker A/B, position θ1/θ2.
4. List the samples with the largest and with the smallest target-stream error, 10 each.
5. **Judgement rules** (judged in order, taking the first satisfied):
   - **Evaluation definition**: of the median errors of the direct references at θ1 and θ2, one is > 10° and the other ≤ 10°.
   - **Output-stream index**: of the median errors grouped by output-stream index, one is > 30° and the other ≤ 10°, and the same split does not appear when grouped by θ1/θ2.
   - **Timing or phase problem**: the errors grouped by θ1/θ2 split (one > 30°, one ≤ 10°), and for the group with the larger error, the median |lag| against its own direct reference is ≥ 2 samples, or the median peak correlation is ≥ 0.2 lower than the other group.
   - None satisfied: **cannot be determined for now**.

## Results of the FaSNet-TAC direction-asymmetry diagnosis
- **Direct references substituted into the estimator**: median error 0.37° at θ1 and 0.38° at θ2, all ≤ 10°. So it is not a problem of the evaluation definition.
- **Grouped by output-stream index**:

| | Median direction error | Proportion with error ≤ 10° | Correlation with own direct reference (median) | Median time offset | Median SI-SDR against own direct reference |
|---|---|---|---|---|---|
| stream 0 | 120.9° | 0.00 | **−0.89** | 0 | 5.97 dB |
| stream 1 | 0.76° | 1.00 | +0.90 | 0 | 6.36 dB |

- Grouped in other ways:
  - θ1 / θ2: median error 77.9° / 2.0°, median correlation −0.81 / +0.81. Stream 0 was selected as the target stream 115/200 times, hence the large error at θ1.
  - s1 / s2: 35.6° / 32.0°, no difference.
  - A / B: 61.5° / 5.4°.
  - Output stream × position: the median error of stream 0 at θ1 and θ2 is 117° / 129°, of stream 1 0.76° / 0.76°. The error therefore depends only on the output-stream index, not on the position.
- **The 10 samples with the largest target-stream error** are all stream 0, with errors of 172–180° and correlations between −0.80 and −0.92, except g074_s1 at −0.20: g032_s2, g005_s2, g074_s1, g092_s1, g063_s2, g063_s1, g083_s2, g083_s1, g049_s2, g026_s1.
- **The 10 samples with the smallest error** are all stream 1, with errors ≤ 0.17° and correlations between +0.76 and +0.97: g034_s1, g084_s1, g030_s1, g057_s1, g096_s1, g096_s2, g080_s1, g009_s2, g010_s1, g010_s2.
- **Judged under the frozen rules: timing or phase problem.**
  - The errors at θ1 and θ2 split, and the group with the larger error (θ1) has a correlation with its own direct reference 1.62 lower than the other group, above the 0.2 threshold.
  - The "output-stream index" rule does not hold, because it requires that the same split not appear when grouped by θ1/θ2, and here it does.
- **Factual note** (description only, no fix): the output of FaSNet-TAC stream 0 has **inverted polarity** relative to its corresponding direct sound, with a correlation of about −0.89 and a time offset of 0.
  - SI-SDR is unaffected by sign, so the separation metrics are unaffected.
  - But the direction estimator uses the phase of the PHAT cross-spectrum, and the sign flip shifts the estimated direction to nearly the opposite direction (172–180°).
  - So the "phase problem" here is specifically the polarity flip of stream 0, which depends only on the output-stream index.
- The stream-selection rule was not changed and nothing was fixed. The v1/v2 verdicts are unchanged.
