## 1. 定义
1. **真实 C6 不定义为"从混合音频估计目标方向"**：混合音频本身不能说明用户要听谁。**目标方向由用户输入提供**（询问方向 θ_query），**声源方向由系统从分离流估计**（v3 的 `doa`，已存在选路文件里）。选路就是比较两路的估计方向与 θ_query。
2. 用户输入用两种方式模拟：**C6-sector**（用户只说出扇区）和 **C6-noise**（用户给出带随机误差的角度）。
3. 固定偏移 δ 继续称为 **C6δ，只作敏感性分析**，不属于真实 C6；已有结果不重跑，只并列引用。
4. 方位约定见 `docs/conditions.md`：相对 mic 0，逆时针为正，(−180°, 180°]，wrap(a) = (a + 180) mod 360 − 180。θ1（位置 0）始终是目标方位，θ2 是干扰者方位；同一组的两个互换样本 θ1、θ2 相同。

## 2. 条件
### 2.1 C6-sector
- 扇区数 K，W = 360°/K。
- **主划分（"中心"）**：mic 0 方向是第 0 扇区的中心。k(θ) = ⌊((θ + W/2) mod 360) / W⌋，中心 c_k = wrap(k·W)。
- **旋转半格（"旋转"，只作敏感性分析）**：k(θ) = ⌊(θ mod 360) / W⌋，中心 c_k = wrap((k + 0.5)·W)。
- 询问方向 θ_query = c_{k(θ1)}。
- **方向不可辨**：k(θ1) = k(θ2)（只用真实方位，作为评估侧标签；按组定义）。
- **主结果：K = 8、中心划分。** K = 4，以及两种 K 下的旋转划分，只作敏感性分析。

### 2.2 C6-noise
- θ_query = wrap(θ1 + ε)，σ ∈ {5°, 10°, 15°}，**重复 10 次**（r = 0, …, 9）。
- **按组抽样**：`rng = np.random.default_rng(np.random.SeedSequence([2026, σ, r]))`，`eps = rng.normal(0, σ, 100)`，按组号升序（0–99）依次分配；同一组的两个互换样本共用同一个 ε。
- **主结果：σ = 10°。** σ = 5°、15° 只作敏感性分析。
- 不定义"方向不可辨"；另按 K = 8 中心划分的真实不可辨标签分开报告，只作描述。

## 3. 选路、正确性与主口径
- **选路**：冻结的 v3 规则（`eval_c6_delta.choose`：取估计方向离 θ_query 最近的一路，一样近时取第 0 路）。两路的估计方向和极性标记用已有选路文件，不重新估计。
- **参考目标路**（只用于评估）：SpatialNet 用 `outputs/frontend_snapshot_eval/spatialnet/per_sample.jsonl` 的 `ref_stream`；FaSNet-TAC 用 `outputs/frontend_mix_v1_eval_v2/eval_v2_per_sample.jsonl` 的 `ref_stream_direct`（与 C6δ 相同）。
- 每个样本的下游输出 = 选中那一路的已有 raw 输出（见 §6），用 `eval_c4_v1.score` 计算类别（binding-score-v1，不修改）。
- **主口径（全部 200 个样本）**：
  - 选路错误：选中路 ≠ 参考目标路，**或者该样本方向不可辨**（不可辨时选路一律不算正确）；
  - "只含目标""目标至少命中一个""目标全部命中"：不可辨样本**记为 0**（不计功）；
  - "只含干扰"：按实际输出计算（不可辨样本也照实计入）；
  - 配对翻转准确率：一组两个互换样本都"只含目标"（计功后）才算对。
- **可辨子集口径**：只用可辨样本，所有指标按实际计算，并报告可辨样本数。同时单独报告**不可辨样本数**（及各夹角层的数目）和不可辨样本上的实际类别分布。
- C6-noise 没有不可辨样本，主口径即全部 200 个样本的实际结果。

## 4. 拒答
- **不拒答**：全部回答。
- **拒答 A（margin）**：margin = |wrap(θ_query − θ̂_另一路)| − |wrap(θ_query − θ̂_选中路)|，**margin < 17° 时拒答**。τ = 17° 固定（C6δ 在 dev 一半上选出），不再调参，用于 C6-sector 和 C6-noise，在全部 200 个样本上评估（τ = 17° 来自 C6δ 的 dev 一半组，这部分组也在本次评估中）。
- **拒答 B（扇区）**：两路的估计方向 θ̂_0、θ̂_1 都落在询问扇区 k(θ_query) 内时拒答。只用估计方向和询问扇区，**不用真实方位，不调参，只用于 C6-sector**（按各自的 K 和划分）。另报告拒答 B 标记与真实"不可辨"标签的 2×2 计数。
- 对每种拒答（含不拒答）报告：**覆盖率**（回答的比例）；已回答样本中的**选路错误率（风险，主口径）**、只含干扰、目标至少命中一个（主口径计功）。
- **风险-覆盖率曲线**：拒答 A 的 τ ∈ {0, 1, …, 90}°，全部 200 个样本，横轴覆盖率、纵轴已回答样本的选路错误率（不加权）；每个前端一个子图，每个条件一条线（C6-noise 用 10 次重复的平均），标出 τ = 17° 和拒答 B 的点。图存为 `docs/figures/c6_real_risk_coverage_v1.png`。

## 5. 加权、置信区间与重复
- **等量夹角**：200 个样本直接平均（四层各 50 个样本）。
- **自然夹角加权**：cv_dev93 的夹角分布 [0,15) 78、[15,30) 96、[30,60) 155、[60,180] 653（共 982）。每个样本的权重 v_i = (w_s / 982) / n_s（n_s 为该样本所在层的样本数）。任意子集（已回答、可辨等）上的加权比例 = Σ v_i x_i / Σ v_i；加权覆盖率 = Σ_已回答 v_i / Σ_全部 v_i。配对翻转准确率不加权。
- **95% 置信区间**：**组级 bootstrap**，按夹角层分层（每层 25 组有放回抽样，同组两个互换样本一起），B = 2000 次，`np.random.default_rng(2026)`，取 2.5% 和 97.5% 分位数。对选路错误率、只含干扰、目标至少命中一个（等量和加权）、覆盖率，以及已回答样本的选路错误率、只含干扰、目标至少命中一个给出区间。配对翻转准确率不给区间。
- **C6-noise**：报告 10 次重复的**平均值和范围（最小–最大）**；置信区间对"10 次平均值"做 bootstrap（每次重抽样后先算 10 次重复的平均，再取分位数）。
- 另报告四层夹角的分层结果（等量）。

## 8. 主线判断（运行前写定，看到结果后不修改；经验值）
- **对象**：SpatialNet 快照 + P2 的两个主结果，分别判断：C6-sector（K = 8、中心划分）和 C6-noise（σ = 10°，10 次重复的平均）。**只用点估计**，按**自然夹角加权**、主口径。
- 记 OI₀ = 不拒答时的加权"只含干扰"。拒答规则 X（C6-sector 为 A 或 B；C6-noise 只有 A）"有效"指：已回答样本上的加权"只含干扰" ≤ 0.5 × OI₀，**且**加权覆盖率 ≥ 0.60。
  1. OI₀ ≥ 0.05，且至少一个拒答规则有效 → **"方向不确定下减少答错"是可行主线**；
  2. OI₀ < 0.02 → **方向不确定性在该条件下是次要问题**；
  3. 其他情况 → **只在小夹角或部分条件下重要**。
- 判断只针对这个快照和这 200 个样本，属于快照诊断。
