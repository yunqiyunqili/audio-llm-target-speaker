# F1 v1：FaSNet-TAC 处理单人完整混响，以及 R1-same（fasnet-single-talker-v1；2026-11-05；规则在运行前写定，看到结果后不修改）

目的：把"FaSNet 处理本身带来的失真"和"残留的两人重叠"分开看。不微调模型，不加入新前端，不修改 mix_v1、P2 prompt、binding-score-v1、已有结果或判定。

## 输入
- 对 mix_v1 的每个样本（200 个），只取**目标说话人**在这个样本里的完整混响 6 麦 image。
  - 方位：s1 的目标 A 在位置 0（θ1），s2 的目标 B 在位置 0（θ1）。
  - 用 mix_v1 manifest 中的增益和 rir_start，以及清单中的偏移，用 `mix_slurp_v1` 的函数在内存中重算。
  - **不加干扰者，不加噪声**。
- 注意：R1 用的是目标录音在 mix_v1 中第一次出现时的 RIR 和位置（见 c3-factor-diag-v1），F1 用的是每个样本自己的 RIR 和位置，两者的 RIR 不完全相同。评估时会报告两者 RIR 和位置完全相同的样本数，并单独给出这部分样本的结果。

## 处理
1. FaSNet-TAC 推理：checkpoint 只读，推理代码与 `frontend_mix_v1.py` 相同（std 归一化 → model → × scale），在 CPU 节点上用 srun 运行，tfgridnet 环境。
2. 选路：**选能量（RMS）较高的那一路**，不使用参考信号。
3. 极性：与 mic 0 输入做零延迟相关，相关为负时取反，与 v3 的规则相同。
4. 选出的那一路（8 kHz，float32）写到 `outputs/fasnet_single_talker_v1/streams/`，只写 outputs，不写 data。
5. 送入 Qwen：`resample_poly(x, 2, 1)[:2T]` → −30 dBFS → 冻结的 P2，不加方向说明；解码设置与 P2 相同，流程与 C5 相同。

## 指标
- 使用 `eval_c4_v1.score` 和 `summ`，不改动。按每个样本自己的配对计算 D_T 和 D_I。
- 报告：只含目标、只含干扰、两者都不含、目标至少命中一个、目标全部命中、配对翻转准确率、M、U。M 与 R1 的口径相同，只看目标本人的 WER < 0.5。
- 另外报告：选中那一路与目标 direct 参考之间的 SI-SDR（只作描述），以及两路的能量比。

## R1-same（2026-11-05 新增，作为 F1 的直接对照）
- 每个 mix_v1 样本使用目标的完整混响 **mic 0** 信号，RIR、位置、增益、偏移都与 F1 相同，不加干扰者和噪声，**不经过 FaSNet**。
- 处理：8 kHz 的 mic 0 完整 image → `resample_poly(x, 2, 1)[:2T]` → −30 dBFS → 冻结的 P2。流程与 F1、C5 相同。
- 指标与 F1 相同；M 只看目标本人。

## 判定（经验值，不是显著性检验；a = 200 个样本上的"目标至少命中一个"；C5 = 0.395）
主判定使用**全部 200 个样本**，并与 **R1-same** 比较：
- |a(F1) − a(R1-same)| ≤ 0.05，并且 a(R1-same) − a(C5) ≥ 0.10：判为"**残留重叠相关的问题更可能**"；
- a(R1-same) − a(F1) ≥ 0.10，并且 |a(F1) − a(C5)| ≤ 0.05：判为"**FaSNet 处理失真更可能**"；
- 其他情况：判为"**介于两者之间或未能区分**"。
- **只作校验，不参与判定**：原 R1（0.575，RIR 取录音第一次出现时的那一组）；以及 RIR 和位置与原 R1 完全相同的 63 个样本上，R1-same 与原 R1 是否一致。
- 只作诊断，不写成因果。
