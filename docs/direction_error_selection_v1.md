# 询问方位误差下的选路准确率 v1（direction-error-selection-v1；2026-11-05；规则在计算前写定，看到结果后不修改）

## 目的
C5 用的是真实方位 θ1。这里检查：询问方位有误差时，冻结的 v3 选路规则还能不能选对。只作诊断，不运行 Qwen，不加入新前端，不修改 mix_v1、v1/v2/v3 的结果或判定。

## 方法
- 输入：现有的 FaSNet-TAC 和 BLSTM+MVDR 输出（`data/mix_v1/separated_v1/`），200 个样本。
- 选路规则：**冻结的 v3 规则**，即零延迟相关极性修正 → `doa` → 取 |wrap(θ̂_k − θ_query)| 最小的一路，一样近时取第 0 路。
  - 两路的估计方向 θ̂_k 与询问方位无关，所以直接用 v3 已算好的值：FaSNet-TAC 取 `outputs/c5_v1/selection.jsonl`，BLSTM+MVDR 取 `outputs/frontend_mix_v1_eval_v3/mix_v1/eval_v3_per_sample.jsonl` 的 `doa_v3`。
- 询问方位 θ_query = wrap(θ1 + δ)，δ ∈ {0, +10, −10, +20, −20} 度。
- 准确率：选中的路与 direct 参考匹配（v2 的 `ref_stream_direct`）一致的比例。direct 参考只用于评估。
- 一致性要求：FaSNet-TAC 在 δ = 0 时的选路，必须与 C5 的选路（`outputs/c5_v1/selection.jsonl`）**逐条一致**，否则停下。
- 分层：夹角（[0,15)、[15,30)、[30,60)、[60,180]）、T60（[0.2,0.3)、[0.3,0.4)、[0.4,0.5]），以及不含 [0,15) 的全部样本。
- 95% 置信区间：以组为单位 bootstrap（两个互换样本一起重抽），10,000 次，`numpy default_rng(2026)`。

## 判定（以 FaSNet-TAC 为主；经验值）
记 acc_±20 = min(δ = +20 时的准确率, δ = −20 时的准确率)，用不含 [0,15) 的 150 个样本计算。
- acc_±20 ≥ 0.95：判为"**方向误差不是当前选路的瓶颈**"；
- acc_±20 < 0.85：判为"**方向不确定性是重要瓶颈**"；
- 其他情况：判为"**只在部分条件下重要**"。
- [0,15) 和 [15,30) 两层另行报告，不参与总体判定。
- BLSTM+MVDR 用同样的方法计算，只作对照，不作判定。
